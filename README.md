# C++ 디자인 패턴 공부

패턴의 이름보다 적용 이유와 구현 방식을 설명할 수 있도록 C++ 예제를 직접 작성합니다.

## 우선 학습

- [ ] Strategy
- [ ] State
- [ ] Observer
- [ ] Command
- [ ] Factory Method / Simple Factory 차이 정리
- [ ] Object Pool (GoF 패턴 목록과 별개)

## 이어서 학습

- [ ] Singleton, Facade, Decorator, Composite, Adapter
- [ ] Template Method, Chain of Responsibility, Builder, Memento

각 패턴 폴더에는 **해결하려는 문제 → 최소 구현 → 게임 예시 → 장단점 → 비슷한 패턴과 차이**를 짧게 남깁니다. 예제는 코드가 추가된 뒤에 표시합니다.
